# 小説企画：全員100点になるまで、授業は終わらない。

塾の英語講師と高校生30人が、**40分の授業＋10分の試験**からなる同じ50分を繰り返す、タイムループ授業サバイバル企画。

## 現在の核

- 主人公は塾の英語講師・御厨誠司（仮・41歳）。
- 生徒は英語が得意とはいえない高校生30人。
- 0〜40分：授業。
- 40〜50分：生徒だけで本番試験。
- 本番は全員共通・毎回同じ、阪大級をイメージした難関英文の下線部和訳。
- 30人全員が合格しない限り、50分前へリセット。
- 御厨は最初から全周回を記憶する。
- 合格した生徒だけ次のループへ記憶を持ち越す。
- 合格者も次周で落ちれば、その次のループでは過去の周回記憶を失う。
- 主人公は授業改善だけでなく、あえて失敗する「捨て周」を使って、生徒・教室・自分自身を研究する。
- 「神授業の正体」「ループの目的」「採点箱の正体」「30/30の先」は未決定。

## ファイル構成

- `novel/00_CANON.md`：現時点で採用済みの正史設定
- `novel/01_LOOP_AND_EXAM.md`：50分ループ・試験・記憶・採点ルール
- `novel/02_TEACHING_STRATEGY.md`：授業攻略、捨て周、人間関係、教師側の危うさ
- `novel/03_STORY_ENGINE.md`：連載を動かす対立・ドラマ装置
- `novel/04_OPEN_QUESTIONS.md`：まだ決めない謎・保留事項
- `novel/characters/00_MAIN_CAST.md`：主人公＋主要生徒
- `novel/characters/01_CLASS_30.md`：生徒30人のキャラクター図鑑

## 制作上の重要方針

この作品を単なる教育ドラマ、感動教師もの、英語学習漫画にはしない。

表面は、**50分タイムループ／全員合格／記憶保持と忘却／攻略チーム／心理戦**を持つサバイバル作品として走らせる。

その下に、教師が生徒を送り出す時間、人を理解することと操作することの境界、できる者と教えられる者の違いなどを置く。ただし、それらを作中で説明的なテーマとして語りすぎない。
